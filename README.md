# 🤖 AI Image Classifier

An AI-powered image classification application built using Python, Hugging Face Transformers, Vision Transformer (ViT), and Gradio.

Upload an image and let the pretrained AI model identify its contents with confidence scores.

## 🚀 Features

- Upload images in JPG, JPEG, and PNG formats
- AI-powered image classification
- Top 3 predicted categories
- Confidence scores for predictions
- Interactive Gradio web interface
- Pretrained Vision Transformer model

## 🛠️ Tech Stack

- Python
- Hugging Face Transformers
- Vision Transformer (ViT)
- PyTorch
- Gradio
- Pillow
- Google Colab

## 🧠 AI Model

Model: `google/vit-base-patch16-224`

Pretrained on ImageNet-1k with 1,000 image categories.

[View Hugging Face Model](https://huggingface.co/google/vit-base-patch16-224)

## ▶️ Run the Project

1. Open the Google Colab notebook.
2. Install the required libraries.
3. Load the pretrained model.
4. Run the Gradio application.
5. Upload an image and view predictions.
